# CRM – שלמה וקסלר, ייעוץ משכנתאות

מערכת לניהול לקוחות (CRM) שנבנתה במיוחד עבור משרד ייעוץ משכנתאות. המערכת בעברית, מימין לשמאל, ורצה ישירות בדפדפן. אין צורך בשרת או בהתקנה.

## יכולות

- **לוח בקרה**: לקוחות פעילים, היקף משכנתאות בטיפול, עסקאות שנחתמו, הכנסות משכר טרחה, יחס המרה ומשימות באיחור.
- **ניהול לקוחות**: פרטים אישיים, מקור הגעה, מטרת המשכנתא, שווי נכס, סכום הלוואה, הכנסה, בנק נבחר ושכר טרחה. אפשר לחפש, לסנן לפי שלב ולייצא ל-Excel (CSV).
- **כרטיס לקוח**:
  - ניתוח ראשוני של יחס מימון (LTV) ויחס החזר מההכנסה
  - רשימת מסמכים נדרשים (תלושים, עו"ש, נסח טאבו, שמאות ועוד) עם מד התקדמות
  - יומן פעילות שמתעד שיחות, פגישות ושינויי שלב
  - משימות אישיות ללקוח
  - קישור ישיר לשיחה ול-WhatsApp
- **לוח תהליכים (Kanban)**: ליד חדש ← פגישת היכרות ← איסוף מסמכים ← הגשה לבנקים ← אישור עקרוני ← משא ומתן ← אישור סופי ← נחתם. מעבירים לקוח בין שלבים בגרירה.
- **משימות**: תאריכי יעד, סימון משימות באיחור ושיוך ללקוח.
- **מחשבון משכנתא**: החזר בשיטת שפיצר ובשיטת קרן שווה, סך ריבית, בדיקת תקרת מימון לפי מטרת ההלוואה, ובדיקת יחס החזר.
- **גיבוי ושחזור**: ייצוא וייבוא של כל הנתונים כקובץ JSON, וגם טעינה של נתוני הדגמה.

## הפעלה

1. מורידים או משכפלים את המאגר.
2. פותחים את `index.html` בדפדפן (Chrome, Edge או Firefox).

לחלופין, אפשר להפעיל את GitHub Pages (Settings ← Pages ← Deploy from branch) ולעבוד מכל מקום.

## אחסון נתונים

הנתונים נשמרים ב-`localStorage` של הדפדפן, במחשב שבו עובדים בלבד. כדאי להוריד גיבוי באופן קבוע ממסך **גיבוי**. כדי להעביר את הנתונים למחשב אחר, מורידים גיבוי ומשחזרים אותו שם.

## מבנה הפרויקט

```
index.html        מבנה הדף והניווט
css/style.css     עיצוב (RTL)
js/storage.js     שכבת הנתונים: שמירה, גיבוי ושחזור
js/mortgage.js    חישובי משכנתא: שפיצר, קרן שווה, LTV, יחס החזר
js/app.js         המסכים והלוגיקה של המערכת
```

## הערה

החישובים במחשבון ותקרות המימון (75% לדירה ראשונה, 70% לדירה חלופית, 50% להשקעה) מבוססים על הנחיות בנק ישראל. הם מיועדים להערכה ראשונית בלבד.
